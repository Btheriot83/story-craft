# Crime of Passion Checklist

Run `universal.md` first, then this.  
**Do not grade as fair-play murder** unless intentionally hybrid and labeled.

## Beginning
- [ ] Cold open in the emotional wound (betrayal/humiliation/jealously charged evidence)
- [ ] Bond felt on-page (why this love/pride matters)
- [ ] Identity threat readable in behavior
- [ ] Token planted for ruined/weaponized return

## Middle
- [ ] Options/exits narrow; obsession escalates
- [ ] Midpoint confirmation **or** mercy refused
- [ ] Confined arena / clock traps parties together
- [ ] Heat maintained (not procedural cool)
- [ ] POV claustrophobic; cast is dyad/triangle

## Ending — STRONG (passion-specific)
- [ ] Irreversible act **on-page** (not merely reported)
- [ ] Aftermath cost on-page (pyrrhic, tragic, moral weight)
- [ ] Loss still registers as loss (revenge doesn’t magically heal)
- [ ] Opening token returns transformed
- [ ] Decisive last image; no smirk-glorify shrug
- [ ] Clearly passion-engine ending (not a puzzle dump)
- [ ] **FAIL:** fade before the choice
- [ ] **FAIL:** act off-page only
- [ ] **FAIL:** clean cool getaway with no inner/outer cost
- [ ] **FAIL:** PSA lecture replacing dramatized consequence

## Pass line
Passion scripts FAIL QA without on-page rupture + aftermath punch.
