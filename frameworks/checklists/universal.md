# Universal Checklist — Story Craft (≤5:00 / ~600–750 words)

Use after drafting. **Any Strong Ending FAIL = script FAIL.**

## Length & form
- [ ] Spoken estimate ≤5:00 (~130–150 wpm)
- [ ] Word count ideally 600–750 (hard ceiling ~900)
- [ ] ≤4 named characters; one narrative thread; no B-plot
- [ ] Single emotional effect named (Poe)

## Beginning (pass required)
- [ ] Cold open in a specific moment (not warm reportage)
- [ ] Within ~30–60s: who wants what + cost of failure
- [ ] Genre promise clear (love / murder / passion)
- [ ] Opening plants a detail/token the ending can echo
- [ ] First lines create a question that pulls forward

## Middle (pass required)
- [ ] Causal escalation (`because` / `but` / `therefore` chain)
- [ ] Midpoint turn (status, knowledge, or intimacy flips)
- [ ] No sag: new info/choice/status ~every 20–30 spoken seconds
- [ ] Timeline always clear to listener
- [ ] Character pressure increases; exits narrow
- [ ] Dialogue late-in / early-out; multi-function details

## Ending — STRONG ENDING GATE (non-negotiable)
- [ ] **PASS:** Decisive change (relationship, knowledge, or moral status)
- [ ] **PASS:** Crisis → climax → short resonant coda (not climax then waffle)
- [ ] **PASS:** Surprising yet inevitable; seeds earlier in text
- [ ] **PASS:** Closes the cold-open loop / echoes opening with new meaning
- [ ] **PASS:** Last image/line would hurt if cut (load-bearing)
- [ ] **FAIL if:** fade-out, shrug, “maybe someday,” soft dissolve
- [ ] **FAIL if:** twist/act with no prior plant / character inconsistency
- [ ] **FAIL if:** long explanation after emotional peak
- [ ] **FAIL if:** ending could be deleted without changing meaning

### Ending strength score
- 3 = punch + resonance + genre promise → **PASS**
- 2 = clear climax, soft coda → **REVISE**
- ≤1 = weak/fade/cheat → **FAIL**

## Agent training rule
If `ending_strength < 3` or any Strong Ending FAIL box is checked, do **not** mark the script production-ready.
