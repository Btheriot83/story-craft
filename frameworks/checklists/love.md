# Love Checklist

Run `universal.md` first, then this.

## Beginning
- [ ] Charged meet / reunion / almost-moment (not bio dump)
- [ ] Attraction + friction both seeded early
- [ ] Stake: what intimacy threatens or costs
- [ ] Tone compatible with HEA/HFN promise

## Middle
- [ ] Adhesion (forced proximity / shared problem)
- [ ] Midpoint intimacy raises cost of walking away
- [ ] Black moment from **wound/lie**, not trivial misunderstanding
- [ ] Each lead’s fear shown in behavior under pressure

## Ending — STRONG (love-specific)
- [ ] Costly on-page choice / gesture **specific** to the wound
- [ ] HEA (clear lasting commitment) **or** HFN (together + clear hopeful next step)
- [ ] Commitment unmistakable — no ambiguous fade
- [ ] Opening image/line echoed with transformed meaning
- [ ] Behavioral change precedes or equals the declaration
- [ ] **FAIL:** misunderstanding fixed by missed text alone
- [ ] **FAIL:** “I love you” with no cost paid
- [ ] **FAIL:** fade on kiss while wound still owns them
- [ ] **FAIL:** unmarked tragic ending sold as romance catalog piece

## Pass line
Love scripts FAIL QA without an earned HEA/HFN punch ending.
