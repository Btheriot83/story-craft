# Murder Checklist

Run `universal.md` first, then this.

## Beginning
- [ ] Crime-adjacent cold open (body / intent / bomb-under-table)
- [ ] Stake for living POV within ~60s
- [ ] Mode clear: fair-play puzzle and/or suspense
- [ ] Cast tight (victim + killer + ≤2)

## Middle
- [ ] ≥2 fair clues with dual readings planted before reveal
- [ ] One complete-feeling false theory (red herring)
- [ ] Midpoint false solve or stake flip
- [ ] Crisis: hero wrong / endangered / morally trapped
- [ ] Timeline consistent (crime-clock vs story-clock)

## Ending — STRONG (murder-specific)
- [ ] Reveal reassembles **already shown** clues (no new decisive fact)
- [ ] ≥1 earlier detail recontextualized
- [ ] Motive fits established character yearning
- [ ] Solution simpler in hindsight; surprising first listen
- [ ] Consequence beat (justice, cost, moral chill) — not stop at name-of-killer
- [ ] Opening token echoed
- [ ] Cut after peak; no lecture denouement
- [ ] **FAIL:** unsolved shrug / “police will handle it” without answer
- [ ] **FAIL:** twin / passage / poison introduced only at end
- [ ] **FAIL:** confession with zero prior fair plants
- [ ] **FAIL:** fade-out before meaning lands

## Pass line
Murder scripts FAIL QA without a fair, punchy reveal + consequence coda.
