# The narration gate
A polished draft is not a verified story. Record evidence for each decision; unknown is not a pass.

## Hard gates
- [ ] Every material factual claim maps to a source and locator in the ledger.
- [ ] No invented dialogue, thoughts, motives, guilt, evidence, injuries or relationships.
- [ ] Allegation, testimony, finding, verdict, appeal and later interpretation remain distinct.
- [ ] Material contradictions and exculpatory context are included.
- [ ] Latest case status is checked; missing central evidence blocks factual sign-off.
- [ ] Chronology is intelligible and every flashback has an explicit time cue.
- [ ] A timed read is over 180 seconds and no more than 300 seconds. Until timed, timing is unverified.
- [ ] Final sentence lands on a named person and a verified consequence, sourced revelation or bounded unresolved question.
- [ ] Fiction, composites and reconstructions are labeled. No fictional evidence is represented as archival.
- [ ] No substantial copied prose; quotations are necessary, accurate and attributed.

## Craft rubric · 0 to 3 each
**Human spine:** 0 = names only; 1 = relationship asserted; 2 = relationship changes stakes; 3 = supported human choices connect the whole story.

**Causality:** 0 = event list; 1 = some connections; 2 = mostly motivated transitions; 3 = each selected moment changes the next or the listener’s understanding.

**Clarity:** 0 = confusing; 1 = jargon or chronology gaps; 2 = understandable with minor friction; 3 = clear aloud on first hearing with precise attribution.

**Ending strength:** 0 = absent; 1 = abstract lesson; 2 = specific but insufficiently supported or detached; 3 = supported, specific, connected to the principal and central question.

**Restraint:** 0 = sensationalized; 1 = gratuitous detail; 2 = mostly proportionate; 3 = precise, humane detail with uncertainty intact.

## Decision
Pass requires every hard gate, ending strength 3, and all other craft dimensions at least 2. This is a local editorial rubric, not a validated measurement. A missing timed read yields **unverified**, not pass. A failed evidence gate yields **blocked**; a craft failure yields **revise**.

Aim for 570–610 narration words and a timed read through about 4:30. Over 4:30 through 5:00 needs an editorial reason and a trimming pass; over 5:00 fails. Do not pad to meet a scene count. A word count outside the guide requires judgment, not automatic factual rejection.

Return the exact weak passage, the reason it fails, and a concrete repair. Recheck every factual change against the ledger.
